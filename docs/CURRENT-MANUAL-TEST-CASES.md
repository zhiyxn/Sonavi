## 使用规则

每项只填写以下一种结果：

- `PASS`：实际结果完全符合预期；
- `FAIL`：已执行且结果不符合预期；
- `BLOCKED`：缺少真实样本、权限、网络条件或硬件，无法执行；
- `NOT TESTED`：尚未执行。

测试时不要在文档、截图名称或聊天中写服务器地址、账号、密码、token、Cookie、Authorization、歌曲 ID 或媒体 URL。遇到网络、播放、缓冲或 scrobble 失败时，先记下用例 ID 和本地时间，再从“设置 → 连接诊断”刷新并导出脱敏日志。
